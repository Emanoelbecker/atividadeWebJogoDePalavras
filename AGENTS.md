# Instruções para agentes

- Os PRDs devem ser **sempre** criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.
- Antes de implementar alterações, consulte o PRD e mantenha o escopo do MVP.
- Preserve a acessibilidade, a responsividade mobile-first e a privacidade dos dados locais.
- Ao concluir mudanças, revise os requisitos e verifique os fluxos principais.
